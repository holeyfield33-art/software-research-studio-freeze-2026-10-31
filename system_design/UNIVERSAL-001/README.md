# UNIVERSAL-001 — Software Research Studio system design

Status: proposed architecture; implementation not started. This is the active design direction following the owner's clarification that Studio must become a universal development system. SurfaceTrace is an optional future evaluation subject, not the architecture target or calibration baseline.

Studio should turn project intent and observed project state into proportionate development decisions, connected artifacts, bounded execution and independently assessable evidence throughout development and operation. It must support starting projects, changing existing projects, investigating failures and maintaining releases.

Read `ARCHITECTURE.md`, `LIFECYCLE.md`, `RESEARCH_MAPPING.json`, then `ROADMAP_AND_GAPS.md`. The mapping resolves actual frozen record IDs, their source references and related relationship records. It establishes provenance, not validation of the new architecture or independent verification of external publications.

The 003R freeze and independent reports remain immutable evidence. The UX-002 decision register remains relevant to UX and evidence handling. Its SurfaceTrace-specific adoption sequence is historical and does not govern this universal design. No frozen selector is promoted to production authority. No MOTHERSHIP dataset is integrated. All new universal requirements use the separate `UNI-` namespace.

Current stage: research synthesis and universal system specification. Completion of this checkpoint means the proposed architecture and its evidence map are reviewable; it does not mean the product, universal applicability or improvement claims have been demonstrated.
